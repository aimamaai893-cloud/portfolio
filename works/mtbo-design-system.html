Design System

MTBO Design System

Components 元件Styles 樣式Atomic Design 原子設計

MTBO 產品的設計系統，以 Atomic Design 方法組織：從色彩、字體等基礎元素，到按鈕、輸入框等元件，再組裝成表格、卡片與整頁模板，統一跨產品的視覺與操作體驗。系統持續建置中（In Progress）。

為保護客戶/作品原始設計檔案，本頁面展示的設計作品均經過降畫質處理。

Architecture

設計系統架構.

整個系統以 Atomic Design 分成四層：原子是最基本的色彩與字體，分子是可獨立使用的元件，有機體是元件組成的複合區塊，模板則是整頁的版面骨架。

Typography

字體排版.

全系統統一使用 Roboto，字體大小以 1rem = 16px 為基準，共六級字階，行高一律 150%，字距 0px。

  1. 文字請統一用 #000000
  2. font size 的 Base 1rem 是 16px
  3. Wording 定義：
    1. Title / Label / Table header 一律採用 Title Case
    2. 其他內文採用 Sentence Case
    3. Button 全大寫

Components

元件.

每個元件都有 SPEC 規格與 USAGE 使用說明：尺寸、樣式、狀態與使用情境都寫清楚，開發與設計照同一份規範走。
