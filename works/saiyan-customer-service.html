Customer Service 客服系統

Call report 通話報表CRM logSatisfaction Report 滿意度報表CS Member Mgmt 客服人員管理

整合通話報表、CRM 紀錄與滿意度報表，協助客服團隊追蹤服務品質與人員管理的後台。

為保護客戶/作品原始設計檔案，本頁面展示的設計作品均經過降畫質處理。

USER FLOW

使用者流程.

針對「未存款嘗試」（No Deposit Attempt）名單，從主管排班、分派名單，到電銷人員外撥與通話紀錄的完整路徑。登入後依角色分成兩條線。

■ 主管 / 組長 Supervisor / Team Lead■ 電銷人員 Telemarketer◆ 判斷點

→
◆ 是否為主管 / 組長？Is a supervisor / Team Lead?
是 → 主管 / 組長否 → 電銷人員

主管 / 組長

排班、分派、報表各自獨立進行，也可直接外撥

向右滑動 →
01報表與查詢通話報表 · 三個分頁

Current：查看當期名單，篩選 Report type、Country。History：Report type 選「No deposit attempt」，依 Country、Date range 查詢歷史紀錄。Performance：依 Supervisor、Report type、Country、Date range 查看績效，預設為 No Deposit Attempt。

→
02報表與查詢History 有資料嗎？

有 → 查看 History；無 → No result found。

→
03排班與分派Weekly Roster 排班

點 Weekly Roster 開啟排班表，依角色顯示範圍：Supervisor 看全部團隊，Team Lead 看自己團隊；可排週、日班／夜班與成員。

→
04排班與分派Daily Assign 每日分派

把玩家名單分派給電銷人員：單一分派（Single assign）或多選批次分派（Multi assign），依國家篩選、選組別與班別，儲存後名單進入電銷人員的 Current 分頁。

Country FilterTeam GroupDay / Night Shift
→
05外撥篩選名單並撥打

在 Current 分頁篩選名單，點 Call 直接外撥；名單無資料時顯示 No result found。

→
06外撥接通了嗎？

是 → 開啟通話系統，通話中查看用戶資訊，點 CRM 按鈕紀錄後儲存；否 → 顯示通話失敗訊息。

電銷人員

處理已分派的名單，外撥並記錄

向右滑動 →
01查看已分派名單通話報表 · Current 分頁

Report type 選「No deposit attempt」；已有 team 時，Country 會自動帶入所屬國家。

e.g. Indonesia
→
02查看已分派名單在清單查看用戶資訊

點 Call 撥打。

→
03接通了嗎？

否 → 顯示通話失敗訊息；是 → 進入通話。

→
04通話中查看用戶資訊

與用戶通話，同時確認用戶資料。

→
05語言相符嗎？

是 → 點 CRM 按鈕，填寫紀錄後儲存；否 → 轉接給其他團隊成員。

→
06轉接其他團隊成員

語言不符時轉接給同語言的團隊成員，後續流程待定。

CRM 紀錄欄位

通話後在 CRM 側邊欄紀錄：溝通方式（預設 Phone call）、語言（預設 Undefined）、聯繫狀態（預設 Unreachable）與回應內容。聯繫狀態全部回寫到 History Tab：

Unreachable 未接通Invalid 號碼錯誤Answered 已接通Hang Up 掛斷電話
