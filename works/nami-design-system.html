Design System

Nami Design System

Components 元件Styles 樣式Atomic Design 原子設計

Nami 產品的設計系統，以 Atomic Design 方法組織：從字體、圖示等基礎元素，到按鈕、輸入框等元件，再組裝成卡片、彈窗與整頁模板，統一跨產品的視覺與操作體驗。系統持續建置中（In Progress）。

為保護客戶/作品原始設計檔案，本頁面展示的設計作品均經過降畫質處理。

Architecture

設計系統架構.

整個系統以 Atomic Design 分成四層：原子是最基本的色彩與字體，分子是可獨立使用的元件，有機體是元件組成的複合區塊，模板則是整頁的版面骨架。

Components

元件.

每個元件都有 SPEC 規格與 USAGE 使用說明：尺寸、樣式、狀態與使用情境都寫清楚，開發與設計照同一份規範走。

  1. 尺寸 Default / Small 兩種；寬度 auto / 150 / 210 / 300 / 335 px
  2. 六種顏色：BrandBlue / Yellow / Indigo / Gray / Cyan / White，每種顏色都有 Fill 與 Outline 版本
  3. 狀態：Normal / Focus / Disabled / Error / Error-msg
  4. 另有 Category button；Normal 按鈕寬度 335 px / 210 px

其他元件與模板的規格都在 Figma 檔案裡，分子層 7 個、有機體層 3 個、模板層 5 個，詳見上方架構。
